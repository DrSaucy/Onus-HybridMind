# Onus-HybridMind

A self-auditing intelligence agent bridging the gap between structured SQL and unstructured PDF contracts to detect procurement leakage.

## Tech Stack

This project is built using modern web development tools to ensure a high-performance, maintainable, and elegant enterprise UI:

- **Framework**: [React](https://react.dev/) with [Vite](https://vitejs.dev/) for lightning-fast bundling.
- **Language**: TypeScript for scalable and type-safe code.
- **Styling**: Tailwind CSS (customized for an ultra-premium, glassmorphism-inspired enterprise B2B aesthetic).
- **Icons**: [Lucide React](https://lucide.dev/).

## Prerequisites

Before you begin, ensure you have the following tools installed on your machine:

- **Node.js** (v18.0 or higher recommended) - [Download Node.js](https://nodejs.org/)
- **npm** (comes bundled with Node.js)
- **Git** (optional, for version control)

## Setup Instructions

Follow these steps to set up and run the development environment locally:

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone <your-repo-url>
   cd Onus-HybridMind
   ```

2. **Navigate to the frontend directory**:
   All frontend code has been moved to the `/frontend` folder. You must enter this directory first:
   ```bash
   cd frontend
   ```

3. **Install dependencies**:
   Run the following command to download all required packages.
   ```bash
   npm install
   ```
   *(Note: You can also use `yarn install` or `pnpm install` if you prefer).*

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Access the application**:
   Open your browser and navigate to the local URL provided in your terminal (usually `http://localhost:5173/`).
